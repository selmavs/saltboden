# Saltboden

## Om projektet
Projektarbete till kursen HTML, CSS och tillgänglighet. Projektet handlar om att skapa en komplett, responsiv och tillgänglig webbplats utifrån en av fyra färdiga mockups. Vi valde att bygga webbplatsen restaurang Saltboden. Sidan är byggd med HTML och CSS/SASS med fokus på tillgänglighet och responsivitet. Vi använde oss av mobile-first med två brytpunkter, tablet och desktop.

## Kompilera SASS
1. Installera tillägget 'Live Sass compiler' i VS code.
2. Öppna projektmappen i VS code.
3. Öppna scss-filen.
4. Klicka på Watch Sass i fältet längst ner.
5. CSS-filen uppdateras och genereras automatiskt när man sparar SCSS-filen.
